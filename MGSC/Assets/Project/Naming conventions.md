# Naming conventions

- All names are PascalCase (not camelCase, not UPPERCASE, not lowercase)
- Everything is in English
- Use descriptive names (e.g. Bell, Table, Cutter, Upgrade, and not Enviro1_FarLeft, AntoninScene, Cylinder327)

## Assets

**Prefabs**

- Prefix : P_
- Suffix (optional) : _VariantName, _XX
- Example : P_Wall_Curved_02



**Textures**

- Prefix : T_
- Suffix (mandatory, only one): _BC (Base color), _N (normal), _AORM, _E (emissive)
- Example : T_MrFesse_BC

**Meshes**

- Prefix : SM_ (unskinned Mesh), SK_ (skinned mesh)
- Suffix (optional) : _VariantName, _XX
- Example : SM_Button_Large


**Shaders**

- Prefix : SH_
- Example : SH_ProgressionGauge

## Scripts

**Features**

- Prefix : F_
- Example : F_Grabbable.cs
